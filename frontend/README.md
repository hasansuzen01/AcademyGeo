# AcademyGeo web

Next.js 16 (App Router) + React 19 + Tailwind CSS 4 + next-intl (Turkish / English). See the [root README](../README.md) for the architecture, setup and test commands.

```bash
npm run dev            # dev server on :3000
npm test               # unit tests (Vitest)
npm run map:build      # re-project the world map into src/lib/world-map.json
```
